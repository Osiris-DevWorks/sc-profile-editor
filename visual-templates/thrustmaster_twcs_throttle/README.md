## Button Layout
The Thrustmaster TWCS Throttle typically includes:
- Main throttle slider
- Throttle rocker (forward/back)
- Analog mini-stick (8-way)
- HAT switch (8-way POV)
- 14+ buttons on throttle body
- Paddle switch on back
- Rudder rocker (optional)
