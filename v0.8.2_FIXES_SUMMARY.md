# v0.8.2 Bug Fixes Summary

## Overview
This release fixes 6 critical issues reported by users with multi-device joystick setups (Virpil alphas, Thrustmaster T16000, etc.).

**Branch**: `develop-v0.8.2`
**Total Commits**: 6 fixes
**Files Modified**: 3 core files

---

## Fixes Implemented

### ✅ Issue #25: Duplicate Action Bindings in Saved XML
**Status**: FIXED & TESTED
- **Problem**: Duplicate action elements appeared in exported XML files
- **Root Cause**: Binding objects were being added multiple times to profile's action_map.actions
- **Solution**: Two-pass deduplication in `on_bindings_changed_from_table()`:
  - Pass 1: Remove duplicate binding object references (by identity)
  - Pass 2: Process modified bindings with validation
- **Commit**: 9b056c5

---

### ✅ Issue #17a: Device-to-Joystick Mapping Not Applied
**Status**: FIXED - Needs Testing
- **Problem**: New/preset profiles didn't respect user's device-to-joystick mappings from Config tab
- **Root Cause**: `_add_missing_joystick_devices()` wasn't loading device mapping configuration
- **Solution**: Enhanced to:
  - Load device mapping from settings
  - Look up mapped joystick slots for detected devices
  - Apply mapped instance numbers (js1, js2, js3) instead of defaults
- **Commit**: 33916ea

---

### ✅ Issue #13: Device Detection UI Not Updating
**Status**: FIXED & TESTED
- **Problem**: Devices were added to profile but UI still showed old device count (only "2 devices")
- **Root Cause**: `display_profile()` wasn't called after `_add_missing_joystick_devices()`
- **Solution**: Call `display_profile()` after adding devices in both:
  - `create_new_profile()`
  - `load_preset_profile()`
- **Result**: Device count and Device View immediately update when devices are detected
- **Commit**: 528c89d

---

### ✅ Issue #14: Button Detection Improvements (Diagnostic)
**Status**: IMPROVED - Diagnostic Logging Added
- **Problem**: All joystick buttons reported as "button 1"
- **Actions Taken**:
  - Added comprehensive logging to track pygame JOYBUTTONDOWN events
  - Log raw event attributes (joy, button) for debugging
  - Validate button numbers are in reasonable range (1-32)
  - Create hidden pygame display window for proper event pumping
  - Add error handling for missing event attributes
- **Result**: Detailed logging will help identify root cause if issue persists
- **Status**: Logging in place for user testing and diagnosis
- **Commit**: f5a1990

---

### ✅ Issue #15: Device Filter Emptying Action Table
**Status**: FIXED - Needs Testing
- **Problem**: Selecting device from filter dropdown caused action table to become empty
- **Root Cause**: Device filter was hiding rows with empty device (unmapped actions)
- **Solution**:
  - Only hide rows if they have a device AND device doesn't match filter
  - Keep unmapped actions visible regardless of device filter
  - Better null checking for device items
- **Commit**: 173b17f

---

### ✅ Issue #17b: Device-to-Joystick Mapping UI Layout
**Status**: FIXED - Needs Testing
- **Problem**: Device mapping section had cropped text and cramped layout
- **Solution**:
  - Set minimum widths: 40px for labels, 200px for combo boxes
  - Set combo box size policy to expand horizontally
  - Improved margins (20, 8) and spacing (15) between elements
  - Set minimum button heights (35px) for better touch targets
- **Result**: Device mapping UI is now properly readable and usable
- **Commit**: cd99c3f

---

### ✅ Issue #16: Device View Tab Showing No Devices
**Status**: RESOLVED - Dependent on #13
- **Note**: This issue was caused by devices not being detected (#13)
- **Resolution**: Fixed by Issue #13 - devices are now added to profile and shown in Device View
- **Status**: Needs testing to verify
