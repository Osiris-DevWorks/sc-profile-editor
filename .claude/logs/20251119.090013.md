## User Feedback

**Issue**: When editing an action from the Controls Table, the RemapDialog shows the "Add New Action" section, which doesn't make sense in that context since users are editing a specific action, not managing multiple actions on a button.

**Request**: Hide the "Add New Action" section when opening RemapDialog from the Controls Table Edit button, but keep it visible when opening from Device View or context menu.

## Implementation Details

### Problem Analysis
- RemapDialog has two different use cases:
  1. **Device View / Context Menu**: Managing multiple actions on a button → needs full dialog with "Add New Action" section
  2. **Controls Table Edit Button**: Editing a specific action → should hide "Add New Action" section for cleaner UX

### Solution Implemented

#### 1. Modified `src/gui/remap_dialog.py`
- Added `single_action_mode: bool = False` parameter to `RemapDialog.__init__()`
- When `single_action_mode=True`:
  - Added `self.single_action_mode = single_action_mode` to store the mode
  - Hide the "Add New Action" QGroupBox with `add_group.hide()`
  - Hide the info label with `info_label.hide()`

#### 2. Modified `src/gui/main_window.py`
- Updated `on_edit_input_clicked()` method (line 1050)
- Changed from: `dialog = RemapDialog(binding.input_code, self.current_profile, self)`
- Changed to: `dialog = RemapDialog(binding.input_code, self.current_profile, self, single_action_mode=True)`

### Verified Backwards Compatibility
Confirmed that other RemapDialog callers still work correctly:
- **qtpdf_device_widget.py:794** (Device View): Uses default `single_action_mode=False` → "Add New Action" visible ✅
- **main_window.py:994** (Context Menu): Uses default `single_action_mode=False` → "Add New Action" visible ✅
- **main_window.py:1050** (Table Edit Button): Uses `single_action_mode=True` → "Add New Action" hidden ✅

### Column Structure (for reference)
The Controls Table uses 7 columns:
- 0: Action Category
- 1: Action
- 2: Label (editable)
- 3: Input (human-readable with raw code in tooltip)
- 4: Device
- 5: Edit (pencil icon button)
- 6: Raw Input Code (hidden)

### Unmapped Actions Detection Pattern
Actions without bindings have input codes ending with underscore: `input_code.rstrip().endswith('_')`
