# Star Citizen Profile Editor

## About This Project

**SC Profile Editor** is a comprehensive tool for Star Citizen players to import, edit, customize, and export their control profiles in human-readable formats. Whether you're managing a complex HOTAS setup, creating reference cards, or sharing configurations with friends, SC Profile Editor makes it easy.

SC Profile Editor is developed by **Osiris DevWorks**, a one-man development studio dedicated to making tools that support gamers.

## The Osiris DevWorks Promise

All Osiris DevWorks tools will be either **completely free** or have a **free tier**. We believe in creating value for the gaming community without paywalls or mandatory subscriptions.
