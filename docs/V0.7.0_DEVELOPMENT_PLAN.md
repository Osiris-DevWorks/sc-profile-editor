## Completion Workflow

For each incomplete template:

### 1. Validation Phase
- [ ] Open existing PDF in Adobe Acrobat
- [ ] Verify all form fields are present and accessible
- [ ] Check field naming convention (js#_buttonN, js#_x, js#_y, etc.)
- [ ] Run validation script: `python scripts/validation/validate_pdf_fields.py`
- [ ] Document any issues found

### 2. Enhancement Phase (if needed)
- [ ] Open InDesign source file (.indd)
- [ ] Fix any missing or incorrectly named fields
- [ ] Adjust field positioning and styling if needed
- [ ] Re-export as interactive PDF
- [ ] Re-validate

### 3. Documentation Phase
- [ ] Create/update `field_mapping.json` if complex button layout
- [ ] Document device specs (button count, axes, hat switches)
- [ ] Add device to template_registry.json if not already present
- [ ] Verify device match patterns are accurate

### 4. Testing Phase
- [ ] Test template rendering in SC Profile Editor
- [ ] Load a profile with this device
- [ ] Verify button labels appear in PDF fields
- [ ] Test export functionality
- [ ] Verify no rendering issues

### 5. Build-Ignore Removal
- [ ] Remove `.build-ignore` file when complete
- [ ] Verify template is included in next build
